# Contributing to GoreeCloud YouTube Player

This repository is an independent GoreeCloud Fork-to-Native development project. Changes should preserve useful baseline behavior while replacing inherited product-specific code incrementally.

Before proposing a change:
- Read docs/fork-to-native.md and UPSTREAM.md.
- Do not remove the AGPL-3.0 license, contributor credits, or required source attributions.
- Include test evidence for changed behavior and privacy, security, native-platform, and accessibility implications.
- Do not introduce upstream account/billing integrations or automatic publishing workflows.
- Do not represent inherited UI as verified Glaze Stable or runtime-tested native code.

Bug reports and contributions belong in this GoreeCloud repository, not upstream.
